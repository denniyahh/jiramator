<!-- Click flag conventions for this plan -->

```python
# --resume: tri-state — absent | present-with-no-arg (auto) | present-with-path
@click.option("--resume", "resume_arg", flag_value="auto", default=None,
              type=click.UNPROCESSED, is_flag=False)
# Use is_flag=False + flag_value to allow `--resume` alone OR `--resume <path>`.
# Click idiom: `--resume` toggles to "auto"; `--resume <path>` sets to the path string.
```

Actually the cleanest Click idiom for tri-state is two options that share a state, OR a custom callback. The simplest portable approach (verified in Click 8.1 docs):

```python
@click.option("--resume", "resume_path", type=click.Path(path_type=Path),
              required=False, default=None,
              help="Resume a previous failed/partial run. Pass a path to a "
                   "specific report, or use --resume-auto to find the latest.")
@click.option("--resume-auto", "resume_auto", is_flag=True, default=False,
              help="Auto-discover the most-recent resumable run for this team config.")
```

But the user spec in CONTEXT.md is `--resume` (no value) for auto and `--resume <path>` for explicit. Implementing that as one flag requires `is_flag=False, flag_value="auto"`:

```python
@click.option(
    "--resume", "resume_arg",
    is_flag=False, flag_value="auto", default=None,
    type=click.STRING,  # we'll Path-coerce ourselves
    help="Resume a previous run. Pass --resume to auto-find latest, "
         "or --resume <path> for a specific report.",
)
```

This is the documented Click recipe for "optional value" flags. Per the Click 8.1 docs (Pattern: Boolean Flags / Multi value): `is_flag=False, flag_value=<sentinel>` makes the flag treat `--resume` (no following arg) as `flag_value`, and `--resume <something>` as that value. Verified pattern.

       def _load_report_file(path: Path) -> RunReport:
           if not path.exists():
               raise click.UsageError(f"Resume report not found: {path}")
           try:
               envelope = json.loads(path.read_text(encoding="utf-8"))
           except (OSError, json.JSONDecodeError) as exc:
               raise click.UsageError(f"Could not parse resume report: {path} — {exc}") from exc
           try:
               return RunReport.from_envelope(envelope)
           except ValueError as exc:
               raise click.UsageError(f"Resume report incompatible: {exc}") from exc
