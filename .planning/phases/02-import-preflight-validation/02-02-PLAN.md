A dict subclass that answers `get`/`__getitem__`/`__contains__` permissively but iterates only explicit entries therefore yields zero problems under `report_off_screen_fields=True`.

Interface consumed later by Plan 03's `run_preflight`: `client.get_createmeta_issue_types(project_key) -> list[{"id","name",...}]`, `client.get_createmeta_fields(project_key, issue_type_id) -> dict[field_id, meta]`.
